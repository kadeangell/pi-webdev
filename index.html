Pi WebDev

An orchestration system for LLM-driven web development. A custom browser, a unified protocol that goes beyond CDP, and tight integration with the Pi coding agent — so an LLM can iterate on a web project at the speed of the dev server, not the speed of Playwright.

This is a comprehensive plan plus a live foundation. Phase 1 Week 1 of the roadmap is in — the orchestration server speaks WDP over WebSocket, the Pi extension client handshakes and round-trips. See Progress for what's built, what was learned, and what the next iteration tackles.

The core thesis is that LLM-driven web development is currently bottlenecked by browser tooling that was designed for human QA engineers, not autonomous agents. Playwright + headless Chrome eats 2-5 seconds per iteration. Tight LLM loops need sub-100ms. A purpose-built browser plus a richer protocol that surfaces build state, type errors, dev-server events, and framework-level introspection — wrapped behind a Pi extension — could change what an agent can do in a working session.

02Honest status

This plan is built on a few bets, some safer than others. Worth being explicit:

Things I'm confident about: the orchestration-server / protocol layer is well-understood territory. Pi's extension model is real, working, and documented. The dev-loop pain is real — Playwright cold starts and screenshot-driven LLM feedback loops are genuinely slow.

Things I'm not sure about:

  • Whether Lightpanda is production-ready enough to base a product on, or whether you'd need to fork and harden it
  • How much of React DevTools' backend protocol is stable and usable from a third-party — this affects framework introspection
  • Whether sub-100ms cold start is achievable when V8 isolation is the binding constraint
  • Whether Pi will remain the right harness in 12 months, or whether you'd outgrow it
  • How much of the protocol survives first contact with real users

These are flagged on the relevant pages with the same "Open question" callout style.

03What to read first

If you have 10 minutes: Architecture and Roadmap. They give you the full shape and the first eight weeks of work.

If you're considering whether to commit: Risks and open questions first. That's where the plan is fragile.

If you want to start building this week: skip to Phase 0 of the roadmap. The fastest first artifact is a Pi extension exposing three browser tools against your latest React project — that's the document that tells you what the protocol should actually look like.
